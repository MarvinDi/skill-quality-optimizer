# 五个坑详细检查规则（示例）

本文是拆分后的 references 文件示例，对应文章中的五个坑。

## 坑一：description 缺少触发条件

检查 description 是否同时包含：(1) 技能做什么，(2) 什么时候调用。

## 坑二：一技多事，未拆分

行数超过 500 行时，拆分为 SKILL.md（概览+导航）+ references/（细节）。

## 坑三：只写要求，不写样例

正文必须包含至少一个代码块输出示例。

## 坑四：多处规则重复

技能、项目规则、系统提示中，同一事只定义一次。

## 坑五：未多 phrasing 测试

同一需求换三种说法，都应触发同一技能。
