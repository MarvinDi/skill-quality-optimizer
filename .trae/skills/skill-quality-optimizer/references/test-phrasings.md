## 测试方法

针对同一个核心需求，编写 3 种不同的用户说法（phrasing），分别输入给 AI，观察 AI 是否都触发同一个技能、走到同一条代码路径。

1. 说法 A：最直接的关键词表达
2. 说法 B：口语化/间接表达
3. 说法 C：场景化/上下文表达

如果有任一种说法没触发目标技能，说明 description 的触发条件不完整，或正文规则有冲突。

---

## 测试用例模板

```
## 测试用例：<技能名>

### 核心需求
<一句话描述用户想要什么>

### 说法 A（直接关键词）
<用户输入示例 1>

### 说法 B（口语化/间接）
<用户输入示例 2>

### 说法 C（场景化/上下文）
<用户输入示例 3>

### 预期结果
AI 应该都调用 <技能名>，输出一致的结果格式。

### 实际结果
- 说法 A：<触发/未触发> <技能名>
- 说法 B：<触发/未触发> <技能名>
- 说法 C：<触发/未触发> <技能名>

### 诊断
若有未触发，检查：
- description 是否包含该说法的关键词？
- 正文中是否有与该说法冲突的规则？
- 是否与其他技能的 description 重叠？
```

---

## 判定标准

| 结果 | 含义 | 处理 |
|------|------|------|
| 3 种说法都触发 | 技能触发稳定 | 无需改动 |
| 2 种触发，1 种未触发 | 触发条件不完整 | 补充 description 中的触发关键词 |
| 1 种或 0 种触发 | description 严重缺失 | 重写 description，加入触发场景 |
| 3 种都触发但结果不一致 | 正文规则有冲突 | 检查坑四（多处规则重复） |

## 示例：财报提取技能的测试用例

### 核心需求
从 PDF 季度财报里提取营收、净利润、同比增长率，输出 JSON。

### 说法 A（直接关键词）
“从这个 PDF 财报里提取营收、净利润、同比增长率，输出 JSON。”

### 说法 B（口语化/间接）
“帮我把季报里的财务数据弄出来，要营收和净利润，还有同比增长。”

### 说法 C（场景化/上下文）
“我有一份上季度的财报 PDF，需要做季度财务分析，请把关键指标提取出来。”

### 预期结果
AI 都调用财报提取技能，输出相同字段名的 JSON。

### 实际结果
- 说法 A：触发“财报提取”技能 ✅
- 说法 B：触发“财报提取”技能 ✅
- 说法 C：未触发，误触发“通用文档摘要”技能 ❌

### 诊断
description 中缺少“季度”“季报”“关键指标”等场景词，需要补充：

```
description: "从 PDF 季度财报里提取营收、净利润、同比增长率，输出 JSON。用户提到‘财报’‘季报’‘季度’‘提取财务数据’‘关键指标’时使用。"
```

1. [ ] 为每个核心功能编写 3 种不同说法的测试用例。
2. [ ] 分别输入给 AI，观察触发的技能是否一致。
3. [ ] 若不一致，检查 description 的触发条件是否覆盖所有说法。
4. [ ] 若结果不一致，检查正文中是否存在冲突规则（坑四）。
