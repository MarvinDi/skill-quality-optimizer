```

## SKILL.md 模板（概览+导航）

```markdown
---
name: <skill-name>
description: <一句话功能+触发条件，<200字符>
---

# <Skill Title>

## 一句话描述
<技能做什么，什么时候用>

## 文件结构
```
{{SKILL_DIR}}/
├── SKILL.md              ← 本文件，概览和导航
└── references/
    ├── <文件1>.md        ← <说明>
    ├── <文件2>.md        ← <说明>
    └── ...
```

## 核心能力
- <能力1>
- <能力2>
- <能力3>

## 使用示例
<简短示例>

## 详细规则
参见 references/ 下对应文件：
- <规则A> → references/<文件A>.md
- <规则B> → references/<文件B>.md

## 快速自查
1. [ ] ...
2. [ ] ...
```

## references/ 文件模板

每个 references 文件按以下结构组织：

```markdown
# <文件标题>

## 目录
- <章节1>
- <章节2>
- ...

## <章节1>
<内容>

## <章节2>
<内容>

## 代码示例
```<lang>
<示例代码>
```
```

### 文件命名规范
- 能看出内容，避免 `doc1.md`、`doc2.md`。
- 使用中文或英文有意义的命名，如 `实测记录.md`、`生图参数.md`。

### 行数控制
- 单个文件超过 100 行，顶部加目录。
- 建议每个文件聚焦一个主题，不跨域。

## 示例：1424 行技能的拆解

### 拆分前

```
SKILL.md: 1424 行
```

### 拆分后

| 文件 | 行数 | 说明 |
|------|------|------|
| SKILL.md | 341 | 概览、能力、使用示例、快速自查、references 导航 |
| references/实测记录.md | 524 | 各模块实测数据和记录 |
| references/生图参数.md | 296 | 图片生成参数说明 |
| references/封面叠字.md | 140 | 封面文字叠加规则 |
| references/排障.md | 68 | 常见问题排查 |
| references/执行示例.md | 55 | 执行示例代码 |

### 改进效果
- AI 加载时只读 341 行（下降 76%）。
- 修改时不需要先搜关键词，341 行从头扫一遍就能定位。
- 每个 references 文件聚焦单一主题，易于维护。
