# Skill Split Template (Example)

SKILL.md keeps overview and navigation; details move to references/.

```
SKILL.md                      ← Overview + navigation (<500 lines)
references/
├── <fileA>.md                ← Details A
├── <fileB>.md                ← Details B
└── <fileC>.md                ← Details C
```

Rules: references one layer deep; single file over 100 lines needs table of contents at top; file names should reveal content.
